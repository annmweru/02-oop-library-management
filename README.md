Library Management System

Overview
A Java application for managing books, borrowing and returning,
with persistent database storage.

Features
- Book management
- Borrow and return functionality
- Book availability tracking
- Database persistence
- Custom exception handling

Technologies
- Java
- JDBC
- MySQL
- Git/GitHub

How it works
1. Add a book
2. Search for a book
3. Borrow a book
4. Return a book5.
5. View all books 
6. View available books5. 
7. View borrowed books
